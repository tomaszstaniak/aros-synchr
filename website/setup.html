Setting up Synchr, step by step

It takes about ten minutes. You go back and forth between two machines: your AROS computer and the other computer that runs Syncthing. Each step says which one it is on.

Before you start

  • The network works on AROS: a web page opens, or ping answers.
  • Synchr is installed on AROS (apkg install synchr, or unpack the archive from the download section).
  • Syncthing is installed on the other computer (downloads). On Windows, macOS and Linux, Syncthing is controlled from a page in your web browser. If it is not open, go to http://127.0.0.1:8384 on that computer. On Android, the Syncthing app has the same steps under similar names.

Part 1: connect the two computers

  1. Other computer

    Show its Device ID

    On Syncthing's page, open Actions (top right) and choose Show ID. A long code appears, eight groups of seven letters and digits, like MFZWI3D-BONSGYC-YLTMRWG-C43ENR5-QXGZDMM-FZWI3DP-BONSGYY-LTMRWAD. Leave it on the screen.

  2. AROS

    Start Synchr

    Double-click Synchr. The first start can take up to a minute: Synchr makes this computer's own Device ID, shown at the top of the window.

  3. AROS

    Add the other computer

    Click Add device... and fill in:

    • Name: one word you choose, for example laptop.
    • Device ID: the code from step 1. Capital or small letters and the dashes do not matter. If you mistype it, Synchr says "This is not a Device ID": the code has a check built in, so a typo cannot connect you to a wrong computer.
    • Address and Port: leave them empty. Synchr finds the other computer by its Device ID.

    Click OK. In a virtual machine with a shared clipboard you can copy the ID and paste it instead of typing.

  4. Other computer

    Accept the AROS computer

    Within a minute or two, Syncthing's page shows a box New Device: the AROS computer, under the name shown in Synchr, wants to connect. Click Add Device, then Save.

    No box after five minutes? See the box never appears below.

  5. AROS

    Check that they see each other

    In Synchr's list of devices, the State of the other computer becomes Connected, or Connected through a relay when a router stands between the two. Until a folder is shared it may add "no folder is shared with it by both sides yet". That is expected: go on with part 2.

Part 2: share a folder

For the first try, share a new, empty folder. Synchronising works both ways, so a file deleted on one side is also deleted on the other. Once you have seen it work, share the folders you really use.

  1. Other computer

    Make a folder and share it with AROS

    Click Add Folder below the list of folders. On the General tab:

    • Folder Label: any name, for example AROS documents.
    • Folder ID: Syncthing fills in a random code. Replace it with a short word that is easy to type on AROS, for example aros-docs.
    • Folder Path: where the folder is kept on this computer.

    On the Sharing tab, tick the AROS computer. Click Save.

    Sharing a folder you already have? Click it in the list, Edit, tick the AROS computer on the Sharing tab and Save. Its Folder ID cannot be changed: you will type it on AROS as it is shown.

  2. AROS

    Add the same folder in Synchr

    Click the other computer once in the list of devices, then click Add folder... and fill in:

    • Folder ID: exactly the Folder ID from step 6. Here capital and small letters do matter.
    • Drawer: the drawer on AROS that should hold the files. The button next to the field opens a file requester. A drawer that does not exist yet is made.

    Click OK.

  3. AROS

    Try it

    The folder's state goes through "Reading the drawer" and "Synchronising" to Up to date. Copy a file into the drawer on AROS: it shows up on the other computer within about a minute (Read again now makes Synchr look at once). Put a file in the folder on the other computer and it arrives on AROS.

Synchronising goes on when you close the window. To have it start with AROS, tick Start with the system. To stop it, choose Stop synchronising and quit in the Project menu.

Part 3: your other computers

You may have Syncthing on several computers, say a laptop, a desktop and a phone. In Synchr each folder is kept in step with one of them. The others get the files through that one, the usual Syncthing way.

  1. Other computer

    Pick one computer for AROS

    Choose the one that is switched on most often, and do parts 1 and 2 with it only. When it is off, AROS waits and catches up as soon as it is back.

  2. Other computers

    Share the folder among them as usual

    On the computer you picked, open the folder's Edit window and tick your other computers on the Sharing tab, then Save. Each of them asks to add the folder: accept it there. If the folder was already shared among them before, there is nothing to do.

    On those other computers, leave the AROS computer unticked. They do not need to know it: what changes on AROS reaches them through the computer you picked, and their changes reach AROS the same way.

  3. AROS

    Different folders from different computers

    A folder can come from another computer than the first one, for example documents from the laptop and music from the desktop. Add that computer in Synchr too (part 1 again), click it in the list of devices, and add its folder with Add folder... (part 2). Each folder stays with the device it was added under.

If it does not work

Synchr says in the State column what it is waiting for. Find the words there:

"not found yet; waiting for it to connect"
Check that Syncthing is running on the other computer and that both computers have a network. The first connection can take a few minutes. If "Use Syncthing's public servers" is not ticked, both computers must be on the same local network.
"the device closed the connection: accept this device there" or "has it accepted this device?"
The other computer has not accepted the AROS computer yet. Do step 4, or add it by hand as described in the next point.
The "New Device" box never appears
Add the AROS computer by hand. On the other computer, click Add Remote Device below the list of devices, type the Device ID shown at the top of Synchr's window, and click Save. Capital or small letters and dashes do not matter there either.
"This is not a Device ID"
A character was mistyped in step 3. Compare it again with the code from step 1; the digits 0, 1 and 8 never occur in a Device ID, so they are read as the letters O, I and B.
"Not shared by the other device yet"
On the other computer, open the folder's Edit window and check that the AROS computer is ticked on the Sharing tab. Then check that the Folder ID is exactly the same on both sides, capital letters included.
"Cannot be used"
The folder's drawer on AROS is missing or cannot be written to, for example a disk that is not mounted or is write-protected. Use Change folder... to choose another drawer.
"Connected through a relay"
This works. The data goes through one of Syncthing's public relays, encrypted so that the relay cannot read it, and is slower than a direct connection. On the same local network the connection is direct.

Still stuck? Write through Patreon or Ko-fi and say what the State column shows. The file Data/engine.log in the Synchr drawer helps; please never send key.pem or cert.pem, they are your computer's identity.
